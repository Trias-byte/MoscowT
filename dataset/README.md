# Данные проекта

Для Docker-запуска используются готовые архивы из `deliverables/` и включённые таблицы расписаний. Дополнительно скачивать исходные транзакции, географию или веса не нужно.

| Каталог | Содержимое |
|---|---|
| `labels/` | Официальные почасовые успешные валидации для обучения и тестов; сохранённая сверка исходных сумм |
| `spravochniki/` | Справочники маршрутов и остановок, используемые подготовкой и тестами |
| `geography/` | Сохранённые датированные выгрузки OpenStreetMap и индекс версий |
| `derived/fleet/` | Подготовленные оценки активности вагонов |
| `derived/schedules-2025/` | Дневной и почасовой выпуск, архивные отправления, источники и ограничения |
| `derived/route_connections/` | Связи остановок маршрутов |
| `derived/moscow_accidents_2025/` | Сохранённый набор ДТП и его паспорт |

Локальные `train.csv` и `test.csv` содержат большие сырые выгрузки исследования. Они исключены из Git и Docker; приложение и основной набор тестов их не читают. `test_submission.csv` дублирует конкурсный шаблон для исследовательских скриптов; переносимый шаблон поставки — `deliverables/competition-template.csv`.

История относится к успешным валидациям, а не к уникальным людям или наполнению вагона. Полнота сырой выгрузки и физическое место посадки из агрегатов не следуют. Правила оперативного импорта не подменяют неизвестные значения нулями.
