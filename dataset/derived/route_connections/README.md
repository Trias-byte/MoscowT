# Связи маршрутов по общим остановкам и направлению

Производный справочник для целевых маршрутов **1, 5, 7, 11, 12, 17, 25, 26, 28, 50**. История валидаций и labels не изменены.

## Файлы и единицы записей

| Файл | Одна строка |
|---|---|
| `same_direction_stops.csv` | Общая остановка и пара направлений маршрутов, откуда можно доехать по одному пути до следующей общей остановки |
| `same_direction_corridors.csv` | Непрерывный общий участок для пары направлений, со списком точек отправления |
| `route_connection_features.csv` | Один целевой маршрут; всего 10 строк, включая маршруты без связей |
| `excluded_common_stops.csv` | Совпавшая остановочная точка, не прошедшая проверку совместного дальнейшего движения |
| `STATIONS.md` | Полный список станций по парам маршрутов и направлениям для чтения |
| `manifest.json` | Источник, дата среза, контрольная сумма, правило и результаты проверок |

CSV: **UTF-8 с BOM, разделитель `;`, десятичная точка**. Идентификаторы остановок имеют префикс `osm-node-`. Числовые номера маршрутов совпадают с `route` в labels. Названия остановок оставлены как в OSM.

## Правило совпадения

1. Совпадает ID узла остановки OSM, а не только название или ближайшие координаты.
2. Роль остановки в обоих маршрутах разрешает посадку: `stop` или `stop_entry_only`.
3. После остановки совпадает направленная последовательность узлов рельсов.
4. До расхождения путей есть следующая общая остановка, допускающая высадку. Она может быть конечной общего участка. Пропуск промежуточной остановки одним маршрутом допускается, если путь до следующей общей остановки полностью совпадает.

Номер направления `0`/`1` локален для маршрута. **Равенство direction_a и direction_b не проверяется.** Для человека направление задано конечными `towards_a` и `towards_b`; устойчивые ключи шаблонов — `relation_a` и `relation_b`.

Общая последняя остановка не становится автоматически общей точкой отправления: после неё трамваи могут разойтись или закончить движение. Например, в одном направлении последняя общая остановка № 5 и 7 — «Лесная улица», поэтому она не входит в список отправления в этом направлении.

Несколько остановок могут называться «Метро „Авиамоторная“». Их нужно различать по `stop_id` и координатам. Эти ID не являются идентификаторами исходного Excel. Сопоставление двух справочников здесь не выполнялось.

## Ключевые поля подробного списка

| Поле | Значение |
|---|---|
| `route_a`, `route_b` | Пара маршрутов, всегда `route_a < route_b` |
| `relation_a`, `relation_b` | ID направлений маршрута в OSM; ссылки `https://www.openstreetmap.org/relation/{id}` |
| `direction_a`, `direction_b` | Обозначения направлений из текущего импортера проекта |
| `towards_a`, `towards_b` | Конечная остановка каждого направления |
| `stop_id`, `stop_name`, `stop_lat`, `stop_lon` | Общая точка отправления |
| `stop_order_a`, `stop_order_b` | Позиция точки в каждом шаблоне |
| `next_common_stop_id`, `next_common_stop_name` | Первая общая остановка впереди на совпадающем пути |
| `same_immediate_next_stop` | Следующая общая остановка непосредственно следующая у обоих маршрутов |
| `shared_to_next_stop_m` | Расстояние по рельсам до следующей общей остановки |
| `corridor_end_stop_id`, `corridor_end_stop_name` | Последняя общая остановка до расхождения путей |
| `remaining_common_corridor_m` | Расстояние по рельсам от текущей до последней общей остановки |
| `downstream_common_stop_count` | Число общих остановок впереди до расхождения |
| `geometry_as_of` | Дата состояния источника: 2026-02-09; не дата начала действия связи |
| `historical_2025_verified` | Везде 0: действительность этих связей в 2025 году не подтверждена |

Ключ подробной таблицы: `(relation_a, relation_b, stop_order_a, stop_order_b)`. Расстояния получены суммой длин рёбер по координатам WGS84, в метрах; это приблизительная длина пути. Суммировать `remaining_common_corridor_m` по строкам нельзя: остатки одного участка перекрываются.

## Присоединение к маршрутному датасету

Для исходного target уровня `route × date × hour` подходит **route_connection_features.csv**:

```python
features = pd.read_csv(
    "dataset/derived/route_connections/route_connection_features.csv",
    sep=";", encoding="utf-8-sig", dtype={"route": "int64"},
)
enriched = labels.merge(features, on="route", how="left", validate="many_to_one")
assert len(enriched) == len(labels)
```

Это пример присоединения для анализа, а не включение признаков в обучающий пайплайн. В сырых `train.csv`/`test.csv` номер сначала извлекают из `ngpt_route`. В них нет остановки и направления события. Присоединять подробную таблицу по одному номеру маршрута нельзя: она размножит строки и суммы валидаций.

Поля маршрутных признаков:

- `same_direction_peer_count` — число других целевых маршрутов с подтверждённым совместным движением;
- `same_direction_peer_routes` — номера этих маршрутов через `|`;
- `shared_departure_stop_positions` — число уникальных остановочных точек отправления, без повторного счёта по разным соседним маршрутам;
- `shared_stop_pair_direction_rows` — число строк подробного справочника с участием маршрута; здесь пары учитываются отдельно;
- `shared_directed_track_m` — длина объединения общих направленных рёбер между общими остановками. Оба направления учтены, общие рёбра нескольких пар не дублируются. Это не длина участка в одном направлении.

### Время и ограничения

Геометрия взята на **9 февраля 2026 года**, а обучение и проверка проекта относятся к **2025 году**. В OSM-срезе могут быть изменения, которых ещё не было на дату наблюдения. Справочник не следует молча включать в историческую проверку модели: сначала нужна историческая география на соответствующие даты либо явно обозначенный эксперимент с поздним справочным срезом.

Связи статические. Они не доказывают одновременное прибытие трамваев, удобство пересадки, остановку конкретной валидации или пассажиропоток на остановке. Для использования потока соседних маршрутов в модели нужны доступные на момент прогноза лаги; фактические значения прогнозируемого часа использовать нельзя.
