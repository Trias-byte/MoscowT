# ДТП Москвы за 2025 год

Источник: [Карта ДТП — открытые данные](https://dtp-stat.ru/opendata/), [прямая выгрузка Москвы](https://dtp-stat.ru/media/opendata/moskva.geojson.zip). Материалы используются с активной ссылкой на [dtp-stat.ru](https://dtp-stat.ru/). Дата получения, запрос, SHA-256, месячное покрытие и геометрия указаны в `manifest.json`.

Нормализованы **8 354 уникальных события**, все 12 месяцев 2025. Сохранены ID, время МСК, координаты, категория/тяжесть и характеристики события. Данные участников не включены в CSV/Parquet/признаки. Неизменённый исходный архив сохранён отдельно; он содержит более широкий период и оригинальную структуру источника.

Файлы: `source.geojson.zip`, `moscow_accidents_2025.csv`, `moscow_accidents_2025.parquet`, `route_candidates.parquet`, `manifest.json`. В рабочем каталоге создаются одноимённые версии `accidents-*` и `accident_links-*`. Для привязки использована датированная геометрия сети, радиус 100 м: **744 пары событие–маршрут**. Это возможное пространственное влияние, не подтверждённое перекрытие; число пар не равно числу уникальных ДТП у трамвая.

Источник преимущественно покрывает ДТП с пострадавшими, а не все задержки движения. Продолжительность перекрытия и момент публикации неизвестны. Рабочие признаки — количество событий за 1/3 часа и покрытие; отсутствие применимой геометрии отделено от нулевого числа событий. Фактические события будущего окна доступны только ретроспективной диагностике.

Воспроизведение из корня репозитория при наличии подготовленной сети:

```bash
backend/.venv/bin/python backend/scripts/prepare_scenario_data.py --kind accidents
```

Повторное скачивание может получить обновлённую исходную выгрузку и другой ID. Для точного воспроизведения добавьте `--archive dataset/derived/moscow_accidents_2025/source.geojson.zip`; команда использует сохранённый ZIP без сети. SHA каждого файла приведён в manifest.
