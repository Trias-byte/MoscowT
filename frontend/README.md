# Поток · frontend v2

React 19, TypeScript, TanStack Query, MapLibre, ECharts. Интерфейс подключён к реальному Python/FastAPI backend.

```bash
npm ci
npm run dev
```

Нужен подготовленный API на `127.0.0.1:8000`; Vite проксирует `/api`. `VITE_DEMO=true` включает явную демонстрацию с синтетическими маршрутными значениями; ошибки реального API никогда не подменяются демо.

- Все десять целевых маршрутов доступны в числовой аналитике и на карте с реальными путями OpenStreetMap. У каждого направления есть упорядоченные остановки; ссылки ведут к исходным объектам OSM. Выбор маршрута приближает его трассу, поиск остановки — её положение.
- Единый календарь с января по декабрь 2025 года. Фактические данные имеют приоритет, при их отсутствии автоматически используется доступный прогноз. Источник подписан на карте, в карточке и таблице. Выбирается одна дата без диапазона. Режимы: «Час», «12 часов» с началом от 00:00 до 12:00 и «Весь день» (00:00–24:00, по умолчанию). Время московское; старые ссылки с месячным или конкурсным диапазоном преобразуются в выбранный день.
- Карта окрашивает маршрут по успешным валидациям за интервал. Часовые границы 200 / 600 / 1 200 / 2 000 приходят из API; последний порог — пиковый красный, предпоследний — жёлтый. Для 12 часов и дня шкала умножается на длительность; цвета и легенда согласованы. Направление, участок, видимая область и дата версии маршрута меняют только карту.
- Остановки доступны для поиска и справочной карточки; остановочных чисел и процентов вместимости нет. Число в кластере — физические остановки, не пассажиры.
- Почасовой график всего дня до четырёх маршрутов, историческое среднее и маршрутная тепловая матрица. Карта, сравнение и таблица показывают сумму выбранных 1, 12 или 24 часов; пропуск любого часа оставляет сумму неизвестной. Таблица работает без WebGL и подложки.
- Экспорт фиксирует текущий snapshot и фильтры, выгружает почасовые строки выбранного интервала или всего дня. Конкурсный CSV отдельный и всегда содержит десять маршрутов и 61 день.
- Запросы отменяются через AbortSignal; Zod проверяет контракт и согласованность версий. Поток и SSE не запрашиваются в P0.
- Параметры просмотра сохраняются в URL, панели — локально. Нативный диалог удерживает фокус. Слайдер всегда виден: из суммы за день движение ползунка или воспроизведение сразу включает просмотр по часам выбранной даты. В режиме «12 часов» ползунок двигает начало интервала. Клавиатура слайдера: стрелки, Home/End; Escape закрывает диалог.

`src/lib/contracts.ts` содержит контракт v2, `src/lib/api.ts` — транспорт и экспорт. [API.md](API.md) описывает HTTP. Справочный JSON демо получен из того же исходного workbook; синтетическими являются числовые фикстуры.

Подложка OpenStreetMap, подписи OpenFreeMap и шрифт Google Fonts требуют интернет. Подложка загружается только для видимой области с обычным кешированием браузера. При сбое подложки сохраняются локальные пути и остановки; при недоступном WebGL — SVG в проекции Меркатора. Можно задать `VITE_MAP_STYLE_URL` для собственной подложки. Карта выбирает архивную версию 2025 года по выбранной дате. Дата версии OSM и ограничения архива подписаны. Отдельный диалог «Загрузить маршрут» проверяет CSV и публикует трассу на заданный период.

```bash
npm test
npm run typecheck
npm run build
npx playwright install chromium
npm run test:e2e
```

E2E запускают Vite и используют настоящий подготовленный backend. При установленном системном Chromium задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Скриншоты desktop/mobile находятся в `test-results/backend-*.png`.
