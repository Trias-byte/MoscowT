# Frontend «Потока»

React 19, TypeScript, Vite, TanStack Query, Zod, MapLibre, ECharts.

```bash
npm ci
npm run dev
```

Vite проксирует `/api` на `127.0.0.1:8000`; API включён по умолчанию. Для встроенного примера без сервера: `VITE_DEMO=true npm run dev`. Основной запуск с готовыми моделями — [Docker Compose](../README.md).

Карта работает через переходный `/api/v1`; панель «Данные и модели», сценарии и backend-оценки участков — через `/api/v2`. Оба API читают одну версию данных. В URL сохраняются снимок, маршруты, дата/час, географический фильтр и ID сценария; свёрнутая панель продолжает опрашивать серверные задания. После перезагрузки задача не теряется. Периоды импорта, обучения, выпуска и экспорта независимы.

Панель поддерживает preview/apply CSV, версии данных, новые маршруты, обучение трёх адаптеров, день/месяц/год, выбор расписания и погодного выпуска, коэффициенты, бюджет вагоно-часов, CSV/Parquet/архив. База и сценарий сравниваются численно; карта получает подтверждённый backend результат. Для годового сценария доступны таблицы по месяцам/дням; вне архива географии остановочные оценки не выдумываются.

`PlatformPanel.tsx` группирует операции с данными; `lib/platform.ts` описывает проверяемые ответы. Маршрутная карта и формы географии остаются отдельными компонентами. `lib/sectionLoad.ts` содержит старую пространственную реализацию только для явно включённого демо/контрольных тестов; в обычном режиме число участка приходит с сервера.

Подложка OpenStreetMap, подписи OpenFreeMap и веб-шрифт требуют сеть. При их недоступности локальные линии и остановки остаются, для недоступного WebGL предусмотрен SVG. Можно задать `VITE_MAP_STYLE_URL` для собственной подложки. Панель адаптирована к мобильной ширине, не перекрывает кнопку закрытия управления маршрутами.

```bash
npm test
npm run build
npx playwright install chromium
MOSCOWT_E2E_MUTATIONS=true PLAYWRIGHT_BASE_URL=http://127.0.0.1:8082 npm run test:e2e
```

Последняя команда — только для изолированного тестового сервиса: публикует контрольную геометрию. Полный прогон: 21 unit-тест и 20 браузерных сценариев. Снимки и traces сохраняются в `test-results/`, не входят в Git. [Контракт и примеры запросов](API.md).
