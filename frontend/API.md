# API

Точный контракт приложения: [Swagger UI](http://localhost:8080/docs) и [OpenAPI JSON](http://localhost:8080/openapi.json). Схема строится из моделей backend при запуске. Клиент проверяет ответы с помощью Zod.

| Префикс                                                                                     | Назначение                                                               |
| ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| `/health/live`, `/health/ready`                                                             | Работоспособность процесса и готовность данных                           |
| `/api/v1/capabilities`                                                                      | Доступные даты, выпуски, маршруты и ограничения                          |
| `/api/v1/network`, `/api/v1/geometry`                                                       | Датированная география и выбранный участок                               |
| `/api/v1/map-snapshot`, `/api/v1/timeseries`, `/api/v1/route-comparison`, `/api/v1/heatmap` | Представления выбранного периода                                         |
| `/api/v2/`                                                                                  | Загрузки, редакции данных, модели, прогнозы, сценарии, задания и экспорт |
| `/api/v2/passengers/`                                                                       | Категории, сезонность, когорты и инфраструктура                          |
| `/metrics`                                                                                  | Метрики Prometheus                                                       |

Временные интервалы полуоткрытые: начало включено, конец исключён. В почасовых запросах нужны полные календарные часы с часовым поясом. Рабочий пояс — `Europe/Moscow`.

Фоновые операции возвращают задание. Клиент передаёт `Idempotency-Key`, опрашивает его статус и скачивает файл после `ready`. Ошибки предметной области содержат `error.code` и `error.message`; ошибки валидации — `detail`.

Карта, графики и выгрузки используют одинаковые идентификаторы редакции, снимка и выпуска. Клиент отклоняет ответы с несовпадающими версиями или неполными рядами. Данные неизвестного часа передаются как `null`.
