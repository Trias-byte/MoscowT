Дополнительно найден открытый исследовательский [MeTS-10](https://arxiv.org/abs/2302.08761), [код и получение](https://github.com/iarai/MeTS-10): дорожные сегменты Москвы и других городов, 15-минутный шаг, периоды 2019–2021. ## Временная корректность

Исторический ERA5 получен в 2026 году; точное время загрузки прежнего архива неизвестно. Для ретроспективной проверки используются только завершившиеся до origin годы. Фактическая погода прогнозируемого окна в модель не попадает. Это реконструированный климатологический сценарий, а не доказательство наличия конкретного метеовыпуска в 2025 году.

Для суточного прогноза можно выбрать сохранённый оперативный выпуск. Backend проверяет `available_at ≤ origin` и покрытие дня, для длинного горизонта отклоняет его. Поле времени инициализации метеомодели не считается временем публикации. [Single Runs API](https://open-meteo.com/en/docs/single-runs-api) не подключён автоматически: исторический hindcast сам по себе не доказывает доступность выпуска до origin. На месяц и год используются исторические погодные сценарии, а не точная будущая погода.

Неизвестные будущие события отсутствуют. Регулярные временные признаки и календарь праздников отделены от школьных каникул: `is_school_holiday=0`, пока нет подтверждённого календаря. Годовой адаптер за пределами опубликованного календаря использует обычный недельный профиль и сообщает о сценарном статусе.

## Эксперимент

Команда из корня: `backend/.venv/bin/python backend/scripts/evaluate_sources.py`. Данные общие для всех вариантов; моменты выпуска 01.04, 01.07, 01.09, 01.10.2025, окно — следующий месяц, отдельно первые сутки. Во всех вариантах LGB=32, CatBoost=48, RF=32, seed=42, те же маршруты, признаки истории и правила cutoff. Варианты: базовый календарь; без календарной группы; календарь+погода; календарь+события.

[Отчёт](source-evaluation.json) содержит ID выпусков, WAPE, MAE, смещение, результаты маршрутов и каждого разбиения. Месячные разности WAPE `без источника − с источником`:

| Календарь | −0,001502 | −0,000125 | +0,002086 | +0,006370 | +0,001707 |

Положительное среднее по четырём срезам не доказывает устойчивого улучшения на новых данных. Периоды уже использовались в исследованиях; независимой итоговой проверки пока нет. Результаты уменьшенного рецепта не переносятся на полный ансамбль. Отдельные метрики полного ансамбля и сезонной модели — [model-validation.json](model-validation.json).
