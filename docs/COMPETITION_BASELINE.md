# Базовая модель поставки

`deliverables/competition-baseline.zip` содержит пять нативных CatBoost-моделей с seeds 42, 17, 123, 2025 и 2026. Рецепт — `cb-mae-sparse14-34f-5seed-v1`, 34 календарных и исторических признака, горизонт до 61 дня от полуночи московского времени.

История поставки: январь–октябрь 2025 года, десять маршрутов. Исходный конкурсный CSV содержит 14 640 строк; его SHA-256:

```text
4adcc1b06ccd53eeddee5637560919396483809fc2da696cae3c1cba013a8d95
```

Указанный в паспорте конкурсный score 0,88 сообщён пользователем и относится только к этому файлу. Переобученная модель не наследует оценку.

## Установка

Docker устанавливает пакет автоматически. Установщик находит историю с совпадающим содержимым, проверяет пакет, выпускает прогноз и сравнивает конкурсный экспорт с эталонной контрольной суммой. Обновление поставки не заменяет более позднюю пользовательскую публикацию.

Для явной локальной установки и публикации:

```bash
backend/.venv/bin/moscowt baseline-install deliverables/competition-baseline.zip --publish
```

Без `--publish` готовится модель и выпуск. Повторная установка того же пакета использует сохранённую квитанцию. Для автономного запуска каталог `ML/` не нужен.

## Правила

История должна быть полной в запрошенном периоде. Неизвестные часы не заполняются произвольными нулями. Нулевая история маршрута даёт нулевой прогноз независимо от его номера. Признаки не используют будущие значения целевой переменной. Конкурсный экспорт округляет неотрицательные значения по правилу half-even; другие режимы имеют свой контракт округления.

Контрольные суммы исходников, окружение обучения и происхождение весов записаны в `deliverables/competition-baseline.manifest.json`. Пути `ML/...` в нём описывают происхождение модели и не используются при запуске приложения.

Проверки: `backend/tests/test_competition_baseline.py`. Они сравнивают конкурсный CSV, перенос пакета, частичные горизонты, устойчивость к добавлению будущих наблюдений и отказ при повреждении весов.
