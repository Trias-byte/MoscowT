Проверки выполнены 25 сентября 2026 года на предоставленных labels и справочнике. Это ретроспективный прогноз ноября–декабря 2025 года. Скрытые фактические значения конкурсного периода не использовались.

Проверены уникальность ключей, допустимость дат и значений, независимость реестра маршрутов от ненулевых строк, повторный импорт, московские границы суток. № 5 сохранён с `no_positive_history`; прогноз для него равен нулю по явной политике. Аномалия № 50 за 20–21 сентября сохранена. История за пределами исходного окна возвращается как `null`.

Обновление 26 сентября 2026: карта использует 21 архивный срез OSM за 2025 год. Для всех срезов проверены координаты остановок и принадлежность каждого ребра линии исходным трамвайным путям. Разорванные направления скрываются. № 5 на 16–18 декабря помечен как реконструкция по официальной дате и геометрии 19 декабря. Полнота временных изменений движения не подтверждена. Современная подложка отделена от архивной геометрии.

## Модель

Каждый временной срез имеет горизонт 61 день. Обучение и сезонный профиль используют только данные до момента выпуска. Признаки CatBoost — маршрут и календарь; будущие фактические лаги отсутствуют.

| Проверка | Сезонный эксперт | CatBoost |
|---|---:|---:|
| Общий WAPE ранних срезов 1 мая и 1 июля | 0,2013746510 | 0,2965033774 |
| WAPE фиксированного контроля сентября–октября | 0,2324161995 | — |

Для контроля выбран сезонный эксперт. После контроля тот же подход переобучен на январе–октябре. Для № 5 знаменатель WAPE равен нулю: WAPE и score публикуются как `null`, абсолютная ошибка — отдельно (0). Итоговый [отчёт модели](../deliverables/backtest.json) содержит показатели каждого маршрута.

Проверены неизменность раннего прогноза при изменении будущей истории, совпадение cutoff модели и выпуска, полная сетка оценки и отсутствие отрицательных/нечисловых значений.

## API, экспорт и устойчивость

Автоматические тесты проверяют общий snapshot числовых ответов, сохранение маршрутов без географии, отсутствие суммирования значений по фрагментам карты, отказ `METRIC_GRAIN_UNAVAILABLE` для остановочных значений и неизменность чисел после фильтрации участка.

Пользовательский экспорт фиксирует числовую область и snapshot. Конкурсный экспорт использует только ключи шаблона и сохраняет их порядок. Sample prediction игнорируется. Округление `floor(value + 0.5)` применяется только в конкурсном CSV.

SQLite сохраняет задание до ответа 202. Проверены повтор ключа идемпотентности, конфликт изменённого запроса, ограничение очереди и восстановление состояния `running` после прерывания.

Дополнительно в настоящем контейнере worker завершён сигналом SIGKILL во время экспорта. После перезапуска worker задание завершилось; затем проверена побайтовая сохранность CSV после полного перезапуска контейнера. Результат — [recovery.json](recovery.json). Команда воспроизведения намеренно перезапускает указанный контейнер:

```bash
uv run --directory backend python scripts/recovery_test.py \
  --url http://127.0.0.1:8081 --container moscowt-app-1 \
  --output ../docs/recovery.json
```

`/health/ready` возвращает 503 при отсутствии требуемых манифестов или Parquet, `/health/live` остаётся доступным. Артефакты и экспорт публикуются атомарно. [Манифест поставки](../deliverables/manifest.json) содержит SHA-256 всех включённых файлов.

## Автоматизация и ограничения проверки

Пройдены: **46 тестов pytest**, Ruff, **13 unit-тестов frontend**, TypeScript, production build и **14 тестов Playwright** против реального API с изолированным каталогом состояния. Дополнительно проверены январский архив, смена трасс по активному дню и после перезагрузки, открытие № 5, проверка ошибочного CSV, выгрузка и обратная загрузка текущей трассы, публикация нового маршрута и исключающая верхняя граница периода. Тестовые маршруты не публиковались в рабочее состояние контейнера.

Повторный запуск полного `bootstrap` сохранил тот же snapshot и SHA-256 конкурсного CSV. Проверены хеши всех 22 файлов архива поставки.

Нагрузочная смесь, ресурсы, задержки и команды воспроизведения приведены отдельно в [PERFORMANCE.md](PERFORMANCE.md). Эти замеры не являются проверкой длительного непрерывного режима и не распространяются на обучение модели или произвольные максимально большие запросы.

Полный raw-аудит в P0 не выполнялся; прежний отчёт указан только как внешний источник сведений. Отложенные функции P1 и ограничения смысла показателя перечислены в [README](../README.md).
