# Проверка внешних факторов

Рецепт CB/LGB/RF: 144/96/64 дерева, веса 70/10/20%. Три фиксированных origin: 01.06, 01.09, 01.10.2025. Обучение каждой модели использует историю до origin. Периоды уже использовались в исследованиях; это не независимый тест.

Во всех вариантах сохраняются базовые часовые/недельные признаки и лаги спроса. «Без календаря» означает исключение дополнительной группы месяца, недели года, праздников и связанных сезонных признаков.

Ниже — арифметические средние трёх месячных почасовых оценок, без взвешивания по длине месяца. WAPE = Σ|прогноз−факт| / Σфакт, MAE = средняя абсолютная ошибка, смещение = среднее(прогноз−факт), две последние метрики — валидации на маршрут/час.

| Режим | Группы признаков | WAPE | MAE | Смещение |
|---|---|---:|---:|---:|
| Оперативный origin | Календарь + погода + ДТП | 0.15014 | 125.66768 | -26.14838 |
| Оперативный origin | Без ДТП | 0.14959 | 125.10235 | -20.99424 |
| Оперативный origin | Без календаря | 0.16846 | 140.82978 | -36.20466 |
| Оперативный origin | Без погоды | 0.14885 | 124.61907 | -28.00458 |
| Ретроспектива | Календарь + погода + ДТП | 0.14829 | 124.21139 | -29.40701 |
| Ретроспектива | Без ДТП | 0.14847 | 124.29931 | -25.77783 |
| Ретроспектива | Без календаря | 0.16489 | 137.81128 | -35.78215 |
| Ретроспектива | Без погоды | 0.14885 | 124.61346 | -27.75815 |

Оперативный режим использует погодный профиль завершённого 2024 года; будущие ДТП не известны. Ретроспектива использует фактические условия окна и не является оценкой оперативного качества. Для ДТП неизвестно время публикации. Исторические признаки отражают пространственную близость к трассе, не доказанное перекрытие.

Положительный средний эффект подтверждён в этом сравнении для календаря (+1,832 процентного пункта WAPE). Погода (−0,129 п.п.) и ДТП (−0,055 п.п.) оперативно ухудшили среднюю метрику. Слабые улучшения ретроспективы нестабильны по периодам и не доказывают причинного эффекта. Расписание не оценивается по выпуску, выведенному из тех же валидаций; ε остаётся пользовательским допущением.

```bash
backend/.venv/bin/python backend/scripts/evaluate_scenario_factors.py
```

Скрипт использует сохранённые версии внешних данных. Обновление архивов/кода даёт новые ID; демонстрационная модель обучается после проверки и не объявляется независимым победителем на этих периодах.
