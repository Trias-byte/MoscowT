# Пассажирская аналитика

`deliverables/passengers.tar.gz` содержит готовые агрегаты за январь–октябрь 2025 года: категории билетов, сезонность, когорты, инфраструктуру и POI. Сумма — 59 667 191 успешная валидация. Сырые поездки и индивидуальные профили карт в приложение не включены.

Docker устанавливает пакет автоматически. Каталог исследовательских расчётов `passenger_dataset/` и GIS-библиотеки для чтения пакета не нужны.

## Интерфейс и API

Вкладка «Пассажиры» показывает категории за выбранное окно, сезонные сравнения и когорты. Карточки маршрутов содержат состав категорий. На карте доступны POI, радиусы 500/1000 м и окружение остановок. Паспорт пакета, словарь билетов и исследовательские метрики доступны в «Данных и моделях».

Префикс API — `/api/v2/passengers`: `metadata`, `query`, `seasonality`, `cohorts`, `infrastructure`, `poi`. Ответы содержат версию, покрытие и фильтры. Если пассажирские агрегаты не согласуются с выбранной историей, сервис сообщает о несовместимости. CSV сохраняет метаданные отображаемого результата.

## Установка и откат

```bash
backend/.venv/bin/moscowt passenger-install deliverables/passengers.tar.gz
backend/.venv/bin/moscowt passenger-activate passengers-<идентификатор-версии>
```

Выпуски хранятся в `DATA_ROOT/passengers/<id>`, активную версию задаёт `current.json`. Установщик проверяет состав архива, размер, пути и хеши, затем атомарно обновляет указатель. Ручной откат сохраняется при повторном запуске того же образа. Переносимый архив сервиса включает пассажирские версии и активный указатель.

`moscowt passenger-prepare --source <подготовленные-таблицы> --output <архив>` нужен только для выпуска нового пакета. Для этого отдельного этапа установите `uv sync --directory backend --frozen --extra models --extra passenger-build`.

## Смысл показателей

Категория описывает билет, а не возраст человека. Карта не равна человеку; уникальные карты нельзя складывать между часами, маршрутами и категориями. Инфраструктура описывает окружение остановок, а не цель поездки. Расстояния рассчитаны по прямой. Место посадки неизвестно. Когорты и сезонные сравнения имеют фиксированные периоды и не превращаются в прогноз по категориям.

Источники и лицензии сохранены внутри пакета: OpenStreetMap (ODbL 1.0), WorldPop (CC BY 4.0). Контрольная сумма архива — в `deliverables/passengers.manifest.json`.
